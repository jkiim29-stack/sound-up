Input compatibility · How readings work

Microphone and Arduino compatibility

USB-A / USB-C / Lightning adapters: if the connected microphone is recognized by the computer or phone as an audio input, it should appear in the microphone list after permission is granted. The connector shape alone does not determine browser support.

Bluetooth microphones/headsets: pair the device in your operating system's Bluetooth settings first, select it as an input device, then refresh the microphone list here. Some Bluetooth headsets change audio modes when their microphone is active, which can affect sound quality.

Arduino Nano: use the Arduino tab on a supported desktop browser, connect the Nano over USB, and select its serial device. This page expects newline-delimited text with a named value such as sound 42. The baud rate is 115200. Close Arduino Serial Monitor before connecting from the website because a serial port generally cannot be used by both at once.

About the measurement

Device microphone mode displays dBFS, a digital signal level relative to the maximum digital amplitude. Arduino mode displays the numeric signal value received over Serial. Neither is automatically dB SPL. Actual dB SPL requires a suitable calibrated microphone and reference calibration. Automatic gain control, noise suppression, microphone placement, and the selected input device can change readings.
