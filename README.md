Title: Sound-Up
It calls you:
  Quiet  under 68 db
  Average  under 75 db
  Loud    over 75 db
It does:
  Quiet  green LED on
  Average  yellow LED on
  Loud    red LED on
For them: you know how loud you are being
To them: it labels you based off your decibil reading
It refuses: it knows how the input of the mic put never shows it
Reminds me of: decibil reader

design.jpeg

You can run this by plugging in the arduino to any USB A plug in. You can blow or make sounds near the audio sensor. You can then view the LCD to notice the display.
